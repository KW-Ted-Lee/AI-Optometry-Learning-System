☁️ V0.7 雲端 AI 後端（Multi-user Classroom）
學生端不再輸入 Gemini API Key。所有 Gemini 請求改由 Cloudflare Worker 代理，API Key 僅保存在 Worker Secret；學生換任何電腦、手機或瀏覽器，只要開啟同一個 GitHub Pages 網址即可使用。
此網址由 GitHub 的 app-config.js 統一設定，不使用本機 localStorage。
☁️ Google Sheet 班級後台
Google Sheet 寫入也改由同一個雲端 Worker 轉送。Apps Script URL 與 CLASS_TOKEN 均由伺服器端管理，學生端不需要知道或輸入。
全站班級與課程選項統一由 app-config.js 管理；更新 GitHub 後，所有學生裝置會一起套用。
⚙️ 教學設定
教師名稱為全站公開設定，請於 app-config.js 修改。
📌 V0.7 Multi-user Classroom Pilot 說明
• 本系統辨識固定版型「眼睛及健康篩檢紀錄表 V3.3」，並以 Recording correctness 為主要規則標準。
• Expected Findings 僅供教科書參照，不自行建立疾病診斷或轉介門檻；臨床判斷仍由教師／驗光專業人員確認。
• 原始影像只保存在目前裝置 IndexedDB；Google Sheet 僅接收學生學習資料、分數、規則結果與去識別化 JSON。
• A 區受檢者個人識別資料不納入 AI 結構化輸出。上傳前仍應採匿名或去識別化教學流程。
• 教師紀錄、學習分析與後台設定已加上 session 密碼鎖；此為前端存取控制，正式版仍應改用後端身分驗證。
• V0.7 已採 Backend / API Proxy：Gemini Key、Google Sheet Web App URL 與 CLASS_TOKEN 不進入學生瀏覽器。
